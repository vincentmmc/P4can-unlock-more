# TSL BLE / 配置块协议

> 本文件由 `tools/more/gen_docs.py` 从 `data/feifan-menu-data.json` 自动生成，请勿手改。

本文只涵盖实现 `更多功能` 页所需的帧与位域，不涉及鉴权细节以外的流程。

## 1. 帧格式

```text
55 7F CMD LEN_H LEN_L [payload] SUM
```

- 校验：`SUM = (CMD + LEN_H + LEN_L + Σpayload) & 0xFF`
- 传输：BLE Service 0000FFF0-0000-1000-8000-00805F9B34FB / Char 0000FFF1, MTU 23, 20B chunk, 串行写队列
- 配置块：configBytes ≥35 字节（设备信息包最长 178 字节）；读 = byte[offset] >>> shift & mask；写 = 清位后置值，整体用 CMD 163 回写；同步回包 160/161/163

实现本页只需要其中四条：

- `0xA3 / 163` —— **写**：按位域清位、置值，整块回写
- `0xAB / 171` —— **读**：256 字节配置块，按位域取值
- `0xA7 / 167` —— 车身动作，payload 为 1 字节动作码
- `0xBB / 187` —— 滚轮/快捷键，payload 为 1 字节值

cfg[offset] = (cfg[offset] & ~(mask << shift)) | ((value & mask) << shift);
